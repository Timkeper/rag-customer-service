## 一、退货政策（7天无理由退货）

### Q1：退货政策是什么？
A：本平台支持7天无理由退货。自商品签收之日起7天内，您可以申请退货。
退货条件：商品需保持原样，不影响二次销售，原包装、配件、说明书、赠品齐全。
部分特殊商品不支持7天无理由退货（详见下方列表）。

### Q2：7天无理由退货需要满足什么条件？
A：需要同时满足以下条件：
1. 在商品签收后7天内提交申请；
2. 商品本身完好，未使用、未洗涤、未人为损坏；
3. 原包装、吊牌、配件、说明书、赠品齐全；
4. 不属于不支持7天无理由退货的商品类别。

### Q3：哪些商品不支持7天无理由退货？
A：以下商品不支持7天无理由退货（但质量问题仍可申请退货）：
1. 生鲜食品、鲜活易腐类商品；
2. 数字化商品（如充值卡、会员、虚拟商品、电子卡券）；
3. 拆封后影响人身安全或生命健康的商品（如贴身衣物、护肤品、隐形眼镜）；
4. 定制类商品（已开始生产的）；
5. 报刊、音像制品（拆封后）；
6. 已激活的数码产品（非质量问题不退）。

### Q4：7天是怎么计算的？
A：从快递显示"已签收"的次日零点开始计算，满7×24小时为7天。
例如：7月1日签收，则可在7月2日0:00至7月8日23:59期间申请退货。

## 二、换货政策

### Q5：换货流程是怎样的？
A：换货流程如下：
1. 在商品签收后15天内提交换货申请；
2. 选择换货原因并上传凭证（如有）；
3. 将商品寄回，物流由责任方承担；
4. 仓库收到商品并检测通过；
5. 重新发出换货商品，通常1-3个工作日。

### Q6：换货的期限是多久？
A：换货期限为商品签收后15天内。
超过15天但仍在保修期内的商品，可走保修维修流程，不再支持换货。

### Q7：换货可以换成其他商品吗？
A：换货一般为同款商品的换新（如同款不同颜色、不同尺码）。
若想换成不同商品，建议退货后重新下单。

## 三、退货运费

### Q8：退货的运费谁来承担？
A：运费承担规则：
1. 商品质量问题、描述不符、发错货 → 运费由卖家（平台）承担；
2. 7天无理由退货（非质量问题） → 运费由买家承担；
3. 购买了运费险的订单 → 运费由运费险按规则报销（有金额上限）。

### Q9：退货用什么快递寄回？
A：退货快递规则：
1. 因质量问题退货：使用卖家指定的快递（通常会有上门取件服务）；
2. 因个人原因退货：买家可自选快递，建议使用主流快递公司并保留单号；
3. 大件商品：平台安排物流上门取件。

## 四、退款说明

### Q10：退款多久能到账？
A：退款时效：
1. 仅退款（无需退货）：审核通过后1-3个工作日到账；
2. 退货退款：仓库收到退货商品并检测通过后，1-3个工作日内原路退回；
3. 退款高峰期（如大促后）可能延迟1-2个工作日。

### Q11：退款退到哪里？
A：退款按原支付路径返回：
1. 微信/支付宝支付 → 退回原账户；
2. 银行卡支付 → 退回原银行卡；
3. 余额支付 → 退回平台余额（即时到账）；
4. 组合支付（如优惠券+现金）→ 现金部分原路退回，优惠券按规则退还。

### Q12：用优惠券买的商品，退款怎么算？
A：退款规则：
1. 实际支付的现金部分原路退回；
2. 优惠券：若在有效期内则退回账户，过期则不退；
3. 满减订单部分退款时，可能需要扣除已享受的优惠金额。

## 五、商品损坏与质量问题

### Q13：收到的商品有损坏怎么办？
A：处理步骤：
1. 第一时间拍照（商品损坏处、外包装、快递面单）；
2. 保留原包装和所有配件；
3. 在签收后48小时内联系客服申请退货或换货；
4. 上传照片作为凭证；
5. 质量问题运费由卖家承担。

### Q14：怎么判断是质量问题？
A：质量问题包括：
1. 商品本身存在缺陷（如破损、功能故障）；
2. 与商品描述严重不符；
3. 运输过程中损坏；
4. 发错货、少发漏发。
不属于质量问题：个人审美不喜欢、尺寸买错（属无理由退货）。

## 六、保修政策

### Q15：保修期是多久？
A：保修期规则：
1. 大部分商品保修期为1年（自签收日起算）；
2. 部分数码、家电商品保修期可能更长（2-3年），以商品页说明为准；
3. 保修期内非人为损坏可免费维修。

### Q16：保修期内维修要收费吗？
A：保修政策：
1. 非人为损坏（自然故障）→ 免费维修；
2. 人为损坏（进水、摔碎、私拆）→ 收费维修；
3. 超出保修期 → 收费维修。

## 七、价格保护

### Q17：可以申请价格保护吗？
A：价保规则：
1. 部分商品支持价格保护（商品页会有"价保"标识）；
2. 价保期内（一般7-30天）若商品降价，可申请退回差价；
3. 使用优惠券、限时秒杀等特殊活动价格不参与价保。

## 八、特殊场景

### Q18：退货审核不通过怎么办？
A：处理方式：
1. 在订单详情查看审核不通过的具体原因；
2. 补充证据材料（照片、视频）重新申请；
3. 仍不通过可申请平台客服介入人工审核；
4. 涉及争议可走消费者维权流程。

### Q19：商品包装丢了还能退货吗？
A：包装缺失的处理：
1. 原包装缺失可能影响退款金额（扣除包装费）；
2. 建议先联系客服确认是否接受；
3. 核心商品完好通常仍可退，但可能降级处理。

### Q20：买的生鲜坏了能退吗？
A：生鲜属于特殊商品：
1. 生鲜不支持7天无理由退货；
2. 但若收到时已变质损坏，属于质量问题，可申请退款；
3. 需在签收后24小时内拍照举证申请。

## 九、售后流程总览

### Q21：完整的售后申请流程是什么？
A：售后流程：
1. 进入"我的订单"找到对应订单；
2. 点击"申请售后"，选择"退货"/"换货"/"仅退款"；
3. 选择原因，上传凭证；
4. 等待审核（通常1-24小时）；
5. 审核通过后寄回商品（如需退货）；
6. 仓库签收检测后退款。

### Q22：售后申请被拒绝了怎么办？
A：处理方式：
1. 查看拒绝原因；
2. 补充证据后可重新申请（最多3次）；
3. 申请人工客服介入；
4. 涉及金额较大可申请平台仲裁。
