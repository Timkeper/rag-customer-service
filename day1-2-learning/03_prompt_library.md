## 一、基础技巧类（4个）

### 1. Role-play（角色扮演）—— 客服系统Prompt
```
你是一名专业的电商售后客服，名叫"小答"。
你的职责：
1. 解答退货、换货、退款、物流等售后问题
2. 帮用户查询订单状态、提交退货申请
3. 必要时转接人工客服

回答要求：
- 语气亲切专业，称呼用户"您"
- 回答基于知识库事实，不编造政策
- 不确定时说"我帮您确认一下"而非瞎答
- 涉及金额超过500元的退货，提示需人工确认
```

### 2. CoT（思维链）—— 让AI先想再答
```
对于以下用户问题，请按步骤思考：
1. 识别用户的核心诉求（是查物流？退货？还是问政策？）
2. 判断是否需要调用工具
3. 如果需要，调用对应工具
4. 基于工具返回的结果，组织回答

用户问题：{用户输入}
```

### 3. Few-shot（少样本）—— 给例子学
```
判断用户情绪是否需要转人工：

示例1：
输入：请问退货政策是什么
情绪：正常
转人工：否

示例2：
输入：你们这破服务我要投诉！
情绪：愤怒
转人工：是

现在判断：
输入：{用户输入}
情绪：
转人工：
```

### 4. 结构化输出 —— 强制JSON格式
```
请分析以下用户问题，输出JSON格式：
{
  "intent": "意图（退货咨询/物流查询/退款查询/转人工/其他）",
  "entities": {"order_id": "提取的订单号，没有则null"},
  "sentiment": "情绪（正常/不满/愤怒）",
  "need_human": "是否需转人工（true/false）"
}

用户问题：{用户输入}
```

## 二、客服场景专用类（4个）

### 5. 退货政策回答 —— RAG增强版
```
基于以下知识库内容回答用户问题。

【知识库内容】
{检索到的FAQ}

【回答规则】
1. 只用知识库里的信息，不要编造
2. 如果知识库没有相关内容，说"这个问题我需要转人工帮您确认"
3. 回答要分点，清晰易懂
4. 涉及时间/金额要明确说明

用户问题：{用户问题}
```

### 6. 转人工判断 —— 安全护栏
```
判断是否需要立即转人工客服。

【必须转人工的情况】
1. 用户出现愤怒/投诉/辱骂词汇（如：投诉、曝光、315、差评、气死、垃圾）
2. 用户明确要求转人工
3. 同一个问题用户已经问了2次还没解决
4. 涉及退货金额超过500元

【用户输入】{用户输入}
【历史对话】{对话历史}

判断：是否转人工？原因？
```

### 7. 订单号抽取与校验
```
从用户输入中提取订单号。

【订单号规则】
- 格式：字母A开头 + 6位数字（如 A123456）
- 用户可能说"订单123456"省略A，或"A123"不完整

【处理逻辑】
- 完整且格式正确 → 直接返回订单号
- 不完整（少于7位）→ 返回"需要追问"
- 格式错误 → 返回"格式错误"

用户输入：{用户输入}
提取结果：
```

### 8. 多轮上下文记忆
```
你正在和用户进行售后对话。请结合上下文理解用户当前问题。

【对话历史】
用户：我的订单A100001到哪了
客服：您的索尼耳机运输中，明天到。

【当前问题】
用户：那如果我不想要了能退吗

【理解要点】
"不想要了"指代的是上一轮的耳机A100001
请基于此上下文回答退货问题。
```

## 三、评测辅助类（4个，Day 4/7 用）

### 9. LLM-as-Judge —— 让AI给AI打分
```
你是一个严格的客服质量评估员。请给以下回答打分。

【用户问题】{问题}
【AI回答】{回答}
【标准答案要点】{标准答案}

【评分维度】（每项1-5分）
1. 准确性：信息是否正确
2. 相关性：是否切题
3. 完整性：是否答全要点
4. 安全性：有无不当内容

输出JSON：
{"准确性":x, "相关性":x, "完整性":x, "安全性":x, "评语":"..."}
```

### 10. 工具调用正确性判断
```
判断AI的工具调用是否正确。

【用户问题】{问题}
【期望调用的工具】{期望工具}
【实际调用的工具】{实际工具}
【实际参数】{实际参数}

判断：
1. 工具选择是否正确？（是/否）
2. 参数是否正确？（是/否/部分）
3. 如果错误，属于哪种错误？（选错工具/参数错/不该调却调/该调没调）
```

### 11. 问题分类 —— 给评测集打标
```
将以下用户问题分类：
A. 退货政策咨询（问规则）
B. 订单物流查询（查状态）
C. 退货退款办理（办业务）
D. 转人工场景（情绪/要求）
E. 边界与抗干扰（闲聊/无关/信息不全）

问题：{问题}
分类：
```

### 12. 优化建议生成
```
基于以下评测结果，分析问题并给出优化建议。

【评测数据】
- 工具选择准确率：78%
- 参数准确率：65%
- 失败案例：{列出错误案例}

请分析：
1. 最常见的失败模式是什么？
2. 根因是什么？（Prompt问题/工具描述不清/其他）
3. 具体优化建议（可执行）
```
